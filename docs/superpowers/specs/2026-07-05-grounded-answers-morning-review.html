🐛 A real bug, caught before merge

The senior review found that ordinary words were hijacking questions: "mac address table on sw1" matched the word "address" and returned the management IP instead — the exact "confidently wrong fact" this feature exists to kill. It also found the fact-shortcut could skip a real command, and two smaller issues.

All fixed at the class level (any table/CLI question skips the fact-shortcut; commands always win) and re-proven. I re-ran the exact broken cases myself:

"mac address table on sw1"→ not a fact ✓ (goes to CLI)
"show ip route on sw1"→ not a fact ✓ (goes to CLI)
"interface status on sw1"→ not a fact ✓ (goes to CLI)
"what version is sw1 running"→ version ✓ (still works)
"ip of sw1"→ IP ✓ (still works)
