The safety rails every task inherits

Read-only, real-only, scope-first — with hard numeric caps so nothing ever runs estate-wide.

Also global

  • Read-only forever, enforced per platform (ios-xe / nx-os / pan-os / f5-tmos).
  • Real data only — unreachable returns an honest status, never fabricated devices.
  • Inventory-driven names — no hardcoded swN; matches real hostnames, IPs, roles, sites.
  • Secrets from .env.local only; SSH creds are per-launch dynamic, never hardcoded.

Honest boundaries

Deliberately not in this plan

Called out so nothing reads as "done" when it isn't.

  • Frontend polish (Plan 1C): dead-code removal in ArtifactPanel.tsx and topology (mermaid) rendering — only the reachability badge is touched here.
  • Inventory search / pagination (Phase 2): today's estate is 4 devices, so search is unfiltered; large-inventory search is a later phase.
  • Real jump-host multi-hop (Phase 4): the SSH executor connects directly to the single sandbox; true bastion channel-forwarding comes with the real network.
  • Firewall / proxy / load-balancer sources (Phase 3): domains stay registered-but-empty until their backends are reachable.
