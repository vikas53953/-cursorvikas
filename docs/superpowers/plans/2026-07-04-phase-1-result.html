Caught in review — before it shipped

🔒 A read-only bypass

The final review found that show running-config | tee flash:… would have quietly written a file to a switch — slipping past the read-only guard. Fixed and verified: write redirects are blocked, while every real read-only command (including show running-config) still works. Two more issues — a scoping bug that could target the wrong routers, and an SSH call that could hang — were also fixed.
